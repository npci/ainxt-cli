## Contributing

AiNxt CLI is NPCI's fork of [Grok Build](https://github.com/xai-org/grok-build),
developed by SpaceXAI and published under the Apache License, Version 2.0. Most
of this tree is theirs.

Questions or patches about the software itself belong with the upstream project.
Please read [upstream's contributing
guide](https://github.com/xai-org/grok-build/blob/main/CONTRIBUTING.md) first —
note that it does **not** accept external pull requests either. External pull
requests and issues are not accepted or triaged here.

The source is published under Apache-2.0 so it can be read, built and forked,
which the licence entitles you to do without asking anyone.
